----
Releasing code to Maven Central

To post a SNAPSHOT:
./gradlew publish

To post a full release:
./gradlew assemble && ./gradlew publishToSonatype -Dorg.gradle.parallel=false && ./gradlew findSonatypeStagingRepository closeSonatypeStagingRepository && ./gradlew findSonatypeStagingRepository releaseSonatypeStagingRepository

A SNAPSHOT is created if SNAPSHOT is in its name.

log onto https://oss.sonatype.org
